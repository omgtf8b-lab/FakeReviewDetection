# Dataset format

Put your research dataset here as CSV with exactly these minimum columns:

- `text`: review content
- `label`: `fake` / `real` (or 1 / 0)

Do not use the tiny demo examples as research evidence. The thesis should report the source, size, preprocessing, train/validation/test split, class balance, baseline, metrics (accuracy, precision, recall, F1, ROC-AUC when applicable), and model version.
